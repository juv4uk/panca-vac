# Дисципліна свідчень (Witness Discipline)

Кожен запис у корпусі описується через фіксований набір полів.
Поле, для якого немає інформації, позначається суворо як `NOT STATED /
NOT EXPLICIT` — без домислювання. `REMAINDER` не означає «помилка» або «порожнє
місце»: це явна фіксація того, що після зіставлення не можна чесно
відновити, пояснити або пов'язати.

## Поля запису

```text
WITNESS                   # конкретний документ/пам'ятка
DATE                      # дата збереженого свідчення
PLACE                     # місце створення/засвідчення
LANGUAGE AS DESCRIBED BY EDITOR
SCRIPT
EXACT FORM                # точно як у джерелі
EXACT SENTENCE            # повне речення
GRAMMATICAL FORM
CONTEXT
REMAINDER                 # що лишилося непідтвердженим або невідновлюваним
```

Тільки після незалежного опису кожного корпусу:

```text
Sanskrit ────────┐
Lithuanian ──────┤
Slovenian ───────┼──→ ALIGNMENT
Ukrainian ───────┤        ↓
Belarusian ──────┘    similarities
                          AND
                       differences
                              ↓
                  REMAINDER / NOT EXPLICIT
```

## Категорії часу (особливо для санскриту)

Найважливіша дисципліна — **не плутати різні дати**:

```text
TEXTUAL COMPOSITION
        ≠
SURVIVING WITNESS
        ≠
DATE OF MANUSCRIPT
```

Текст може бути за складом на тисячоліття старший за фізичний рукопис,
який його містить. Не можна записувати:

```text
Ṛgveda
1500 BCE
→ наш документ 1500 BCE    ❌
```

Натомість вказуємо конкретний фізичний свідок (рукопис, береста,
напис) з його власною датою.

## Ранні практичні корпуси п'яти мов (скринінг 2026-09-05)

| Мова        | Ранній практичний корпус                | Дата збереженого свідчення |
| ----------- | --------------------------------------- | --------------------------: |
| Санскрит    | ранні написи + рукописи; ведичний корпус | античність; рукописи значно пізніші за тексти |
| Словенська  | **Brižinski spomeniki / Freising Manuscripts** | бл. 1000 |
| Українська  | ранній руський корпус → староукраїнська писемна традиція; контроль — **Пересопницьке Євангеліє** | XI–XVI ст., залежно від критерію |
| Білоруська  | русько-ВКЛ канцелярська традиція → **Скорина** | XIV–XVI ст. |
| Литовська   | молитви/глоси → **Mažvydas Catechism**  | бл. 1500–1530; 1547 |

## Відкриті питання стилю

- Засвідченість **двоїни**: які форми числа реально зафіксовані (напр.
  у Freising Manuscripts ≈ 1000 року) — і як це порівнюється з
  санскритською та сучасною словенською/литовською?
- Чи насправді п'ять корпусів дають контрприклади та проміжні стани,
  чи вони підтримують одна одну?
