# Observation template

Один файл = одна **форма / конструкція / відсутність** у **одному** свідкові.
Без alignment і без гіпотез про спадковість.

Скопіюй і заповни. Порожнє поле → `NOT STATED` / `NOT EXPLICIT` / `UNATTESTED IN SLICE`.

```text
OBSERVATION_ID:
LANGUAGE:              # sa | lt | sl | uk | be
WITNESS:               # документ / рукопис
DATE:                  # дата ЗБЕРЕЖЕНОГО свідчення (не «складу тексту»)
PLACE:
LANGUAGE_AS_DESCRIBED_BY_EDITOR:
SCRIPT:
SOURCE_FILE:           # шлях у corpus/
WITNESS_STATUS:        # LIVE-TEXT | PARTIAL | SECONDARY

EXACT_FORM:            # як у джерелі / критичному шарі (вказати який)
EXACT_SENTENCE:        # повне речення або достатній контекст
GRAMMATICAL_FORM:      # лише те, що видно з форми + редакції
CONTEXT:               # прагматика в тексті (до кого звернення тощо)

WHAT_IS_ATTESTED:
WHAT_IS_UNATTESTED_IN_SLICE:
WHAT_IS_NOT_TESTABLE:  # чого текст принципово не може показати

NOTES:                 # без SAME FORM = inheritance
```

Правила:
1. Не змішувати TEXTUAL COMPOSITION і DATE OF MANUSCRIPT.
2. Не виводити «мову загалом» зі зрізу одного жанру.
3. Відсутність у зрізі ≠ відсутність у мові (тип: text-contingent | structural | unknown).
