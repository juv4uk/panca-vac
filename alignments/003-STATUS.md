## Правило

```text
Це кандидатський probe, не результат. НЕ повідомляти "003 established"
і не цитувати як міжмовний доказ ніде, доки не буде заблоковано
справжнього другого свідка під тим самим genre_lock. Один свідок, що
показує внутрішньотекстовий патерн ОД/МН за рамкою адресата, — реальний

спадковість») — але сам по собі не є порівняльним результатом.
```

## Стан

003 = один locked свідок (uk-004), один access-blocked кандидат (be
Апостол 1525), два обґрунтовані структурні виключення (sl, lt), одне
відкрите питання (sa). Жодної заяви про спадковість. Гіпотези порожні.
